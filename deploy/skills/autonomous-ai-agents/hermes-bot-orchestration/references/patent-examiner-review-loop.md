# 专利审查员预审闭环经验（2026-09-04 实测，5 案全流程）

供调度方（主会话/hermes）驱动 patent_examiner 审查 + reviser 修订时参考。这是 bot 协作层面的操作经验，放入 bot-orchestration（patent-workflow 为 user-owned 不可改）。

## 闭环流程（已实测跑通）

```
双PASS(reviewer+auditor) → examiner 预审(审查意见书N) → FAIL → reviser 修订(vN+1) → examiner 复审(复审意见书) → ... 收敛
```

5 案全部先 FAIL，经 2~3 轮闭环：案件3 达 PASS（带条件），其余收敛到结构性瓶颈（创造性需数据/降级/发明人决策，非文本可解）。

## 驱动方式（已踩过的坑）

- **同 bot 批量任务勿并行 message_agent**：一次给同一 bot 发 5 条 message_agent，Bot Chat 串行 → 4 条 `target_busy` 被拒。改为逐案写 query-file 用 `hermes -p <bot> chat -Q --query-file <f>` CLI 直投（独立进程，不占 Bot Chat）。
- 每轮任务书写法（CLI 直投）：自包含（bot 无上下文）→ 给审查对象绝对路径 + 上一轮意见书路径 + 修订说明路径 → 列本轮审查重点（哪些验证项）→ 指定输出文件命名（审查意见书-案件N-复审.md / -三审.md）→ 一次性无交互、[待补充] 不编造。
- 复审任务书里要带"reviser 声称的修订"摘要 + 让 examiner 独立核验（不采信自述）：如"C1/C2 数学修正是否正确（重点验算）""是否真实落地（vs 文字包装）""有无新引入问题"。

## 审查意见书结构（examiner 输出，reviser 据此修订）

1. 最接近现有技术认定（引用具体对比文件，标段落/行号）
2. 区别技术特征表（含每特征对应对比文件公开内容）
3. 区别特征实际解决的技术问题
4. 逐特征显而易见性分析 + **审查员示范表述**（实审通知书口吻，供 reviser 预演）
5. 清晰性/充分公开缺陷清单（编号 C/N/R，标严重度：必修/建议/可选）
6. 修订方向建议（收敛清单，P0/P1/P2 分层）
7. 复审判定 PASS/FAIL + 下次 PASS 准据

## FAIL 两类，处置不同（关键决策）

| 类型 | 特征 | 能否文本修订解 | 处置 |
|---|---|---|---|
| **收敛性 FAIL** | 数学/逻辑/表述硬伤：公式符号错、非标准熵定义、正文-伪代码不一致、边界覆盖缝隙、实施例与公式矛盾、前向引用 | 能，通常一轮闭环 | reviser 按意见书 P0 必修项修，修完复审放行 |
| **结构性 FAIL** | 创造性本质不成立：区别特征=公知/显而易见、来源论文构成现有技术、无实验数据支撑"显著进步" | 不能 | 用户决策：补实验数据 / 降级保护范围（主权利要求退守最可能独立的区别特征）/ 机制依赖升级 / 接受风险 |

## examiner 反复识别的缺陷模式（5 案共性）

- **数学自洽**：公式必须标准定义（标准熵 Σp=1、条件熵链式法则 IG≥0）、符号与正文闭环。examiner 抓到 reviewer 全 PASS 都没发现的：式3 期望熵负号错误、式2 多属性混合求和非标准熵
- **文字包装**：把"共因/并行"说成"因果驱动"、把"离散查表值"说成"连续系数"、把"人工选择"说成"自动调度"。诚实降级（如实承认并行）消除指控，但创造性变弱
- **矮化对比文件**：交底书称对比文件"未公开 X"但源材料实际有——实审中自伤。描述必须逐字对照源材料
- **实施例-公式矛盾**：公式表达不了实施例声称的情形（如式2 只能表达"正×回避"却举例"两正向互斥"），修订引入新矛盾最常见
- **正文-伪代码不一致**：守卫/出口/状态转移规则正文有、伪代码无（或反之），自检"判定一致"声明常不实
- **边界覆盖缝隙**：时段/状态/参数配置留空白（t_bed 可配但时段表固定边界→缝隙/重叠），需全派生连续分区+非法校验+反例验证
- **自供 NPL 反噬**：申请人自供 arXiv 论文在审查员手里=现有技术证据，"思想已公开"挤压创新含金量。解法=表达层差异做足 + 如实声明"不主张建模思想增量"

## 创造性救法（结构性 FAIL 时给用户的选项）

1. **实验/消融数据**：唯一能翻"显著进步"判定的证据。如案件1 需"A 组在库外信息类查询相对 B 组领先"
2. **降级保护范围**：主权利要求退守到最可能独立的区别特征（examiner 意见书会指出哪个最独立，如"D2 置信度无排序通路"→退守排序融合通路），其余降从属
3. **机制依赖升级**：给被否定的特征补真实数据流依赖（如 SI_max 依赖 Q_eff），使特征间协同成立——但需发明人决策，reviser 不擅改，标 [待确认]
4. **诚实降级**：承认并行/常规，消除文字包装指控，接受创造性变弱（比被实审驳回更稳妥）

## 定稿门禁口径（examiner 会明示）

- 若门禁=可实施性/论证严谨性 → 修订达标即可定稿
- 若门禁=创造性成立 → 无数据/无正式检索下不能积极确认，须随附风险声明，把"放行条件"（申请日确认、参数复核、A/B/C 数据）逐条列明交负责人决策
